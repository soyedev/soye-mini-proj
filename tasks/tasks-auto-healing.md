## 1. 문서 정보

- 프로젝트명: 서울 청년 주거지원 비교·이사 체크리스트 자가 치유 서비스
- 기반 PRD: `docs/prd-auto-healing.md`

## 2. 프로젝트 목표

승인된 PRD에 따라 서울 청년 주거지원 예시 정책 3개를 결정적 규칙으로 비교하고, 체크리스트·사건 타임라인을 PostgreSQL에 저장하며, 네 가지 모의 장애를 제한적으로 복구하거나 안전 중단하는 3일 학습용 MVP를 구현한다. 복구 성공은 별도 읽기 전용 검증을 통과한 경우에만 기록한다.

## 3. 작업 원칙

- 요구사항 근거는 승인된 PRD뿐이다. 신규 기능·실제 외부 연동·실사용 개인정보는 범위에 추가하지 않는다.
- 에이전트 역할은 우선 일반 모듈·고정 규칙으로 구현한다. 별도 LLM 에이전트 프레임워크는 PRD 요구사항이 아니다.
- 자동 실행은 allowlist 모의 기능에 한정한다. 셸·임의 SQL·직접 DB 쓰기·실제 신청은 금지한다.
- 최초 호출 포함 최대 4회, 대기 1초·2.5초·5초에 ±20% 지터, 정책 검색 3초 타임아웃, 역할별 3초, 전체 워크플로 30초를 적용한다.
- 30초 예산이 끝나면 현재 요청을 `SAFE_STOP`한다. 회로 half-open은 20초 냉각 후 별도 호출로 확인한다.
- 합성 프로필만 사용한다. 사건 로그는 30일 보존 대상으로 기록한다.
- 모든 작업은 `[ ] pending`으로 시작한다. 구현·테스트·배포는 이 작업목록 승인 후 별도 단계에서 수행한다.
- 기술 선택은 PRD에서 고정하지 않았다. Python 사용 여부, 진입점(CLI/API), 의존성 관리와 로컬 PostgreSQL 기동 방식은 작업 1.1에서 구현 전에 확인한다. 우선 후보는 Python, 로컬 CLI 시연, Docker Compose이나 미승인 선택으로 취급한다.

## 7. 작업 의존성

```text
1.1 → 1.2
1.2 → 2.1 → 2.2 → 2.3

3.2 → 4.2; 3.1 + 3.2 → 4.3
```
